## 종류
비교 다이어그램(블록/스택형). 학부 교과 이수 구조(교양/전공/일반선택 학점 블록)를 "현재" / "접근법 1" / "접근법 2" 세 가지 안으로 나란히 비교하여, AI/AX 교과목을 이수 구조에 어떻게 편입·활성화할지를 보여준다. 화살표로 블록 간 관계를 표시한다.

## 전사(글자)

### 칼럼 1 — 현재
- 교양 (25~30)
  - (초록 박스) 인공지능과 디지털사고
- 전공 (63~106)
- 일반선택 (6~30)  ↔ (양방향 화살표) → AI/AX 교과목 (라벨: Institutional)
- 하단 설명: **현재**  /  AI/AX 교과목 수강 동인 낮음

### 칼럼 2 — 접근법 1
- 교양 (25~30)
  - (초록 박스) 인공지능과 디지털사고
- 전공
  - (짙은 박스, 강조) ?학점까지 전공선택으로 인정 (Code Share)  ↔ (주황 양방향 화살표) → AI/AX 교과목 (라벨: Institutional)
- 일반선택  ↔ (양방향 화살표) → AI/AX 교과목 (라벨: Institutional)
- 하단 설명: **접근법 1**  /  학과에서 지정한 AI/AX 교과목들을 수강 시 일정 학점까지 전공선택 교과로 인정

### 칼럼 3 — 접근법 2
- 교양
- AI/AX
  - (초록 박스) 인공지능과 디지털사고  ← (남색 화살표, 왼쪽 방향) ← AI/AX 교과목
- 전공
- 일반선택
- 하단 설명: **접근법 2**  /  AI/AX를 마치 교양교육과정처럼 별개의 교육과정으로 승격

## 구조 설명
- 세 개의 칼럼이 점선으로 구분되어 좌(현재) → 중(접근법 1) → 우(접근법 2) 순으로 나열된 비교 구조이다.
- 각 칼럼은 학부 이수 학점을 위에서 아래로 쌓은 스택(블록)으로 표현된다: 교양(상단, 25~30학점) / 전공(중앙, 63~106학점) / 일반선택(하단, 6~30학점). 교양 블록 내부에는 초록색의 "인공지능과 디지털사고" 과목이 들어 있다.
- "AI/AX 교과목"(회색, Institutional로 표기된 별도 교과 묶음)이 각 칼럼에서 어떤 학점 블록과 연결되는지가 화살표로 다르게 표현된다.
  - 현재: AI/AX 교과목이 "일반선택"과만 양방향으로 연결 → 수강 동인이 낮음.
  - 접근법 1: AI/AX 교과목이 "일반선택"뿐 아니라 "전공"의 일부(?학점까지 전공선택으로 인정, Code Share, 짙은 강조 박스)와도 주황색 화살표로 연결 → 학과 지정 AI/AX 과목을 일정 학점까지 전공선택으로 인정.
  - 접근법 2: AI/AX를 교양과 전공 사이에 "AI/AX"라는 독립 블록으로 승격하고, AI/AX 교과목이 그 블록(인공지능과 디지털사고 포함)으로 편입되도록 화살표 연결 → 교양교육과정처럼 별개의 교육과정으로 격상.
- 색상 구분: 교양=초록 강조(인공지능과 디지털사고), 전공=파랑 계열, 일반선택=보라/연보라, AI/AX 교과목 묶음=회색(Institutional 노란 라벨), 강조 연결은 주황·남색 화살표로 표시한다.
