## 컨트롤

### 📊 지표

- 재학생 (enroll) — 기본 선택 (학부 + 일반대학원 + 전문대학원 정원내/정원외 누적)
- 대학원재학생 (grad) — 일반대학원 + 전문대학원 정원내/정원외 누적

### 🏫 비교 대상

- 거점국립대 (기본 선택)
- 서울대+과학원
- 주요 사립대
- 개별 대학 ▾ (선택 시 개별 대학 드롭다운 노출)

개별 대학 선택 드롭다운: 부산대학교를 제외한 전체 대학 목록(아래 18개 대학 중 부산대 외 17개)에서 선택.

## 차트 구성 (누적 막대, Canvas 렌더링)

- 부산대학교가 항상 첫 번째로 표시되며 진한 테두리(#1a1a2e)로 강조.
- 스택 구성(재학생 지표): 학부(연한색) → 일반대학원(중간색) → 전문대학원(진한색), 정원외는 빗금(hatch) 표시.
- 스택 구성(대학원재학생 지표): 일반대학원(중간색) → 전문대학원(진한색), 정원외 빗금.
- 색상은 학교별 3단계 팔레트(연한·중간·진한) 사용.
- Y축: 인원 (명). 10,000 이상은 "만" 단위 라벨.
- 5년 단위(2021 경계 등) 굵은 구분선. 2025년 라벨 굵게.

### 범례 — 구성(음영)

- 재학생 지표: 연한색 = 학부 / 중간색 = 일반대학원 / 진한색 = 전문대학원 / 빗금 = 정원외
- 대학원재학생 지표: 중간색 = 일반대학원 / 진한색 = 전문대학원 / 빗금 = 정원외
