## ⚠️ 알려진 한계 / 주의사항 (원본 측 결함 및 외부 의존)

1. **part1·part3 페이지 원본 말미 잘림(원본 사이트 자체 결함).**
   라이브 배포본에서도 동일하게 본문이 태그 중간에서 끊깁니다 — 내가 누락한 것이 아니라 **원본이 그렇게 배포**되어 있습니다.
   - `part3.html`: "🎯 전략 요약 — 5대 핵심 전략" 박스의 **첫 항목이 `<div style="`에서 잘림** → 5대 전략 항목 본문이 원본에 부재.
   - `part1.html`: 국방안심존 이미지 뒤 마지막 배너가 `<span styl`에서 잘림.
   - `part2.html`: "학생 AI 역량 측정 및 환류" 박스까지는 온전하나 마지막 섹션 래퍼가 닫히지 않음(콘텐츠 손실은 없음).
   - 각 `.md` 해당 위치에 "추출 주" 메모로 표기해 두었습니다.

2. **외부 엑셀 파일 미존재.** `grad_s3_3_uglink_guide`가 "학년별_수료학점.xlsx"를 언급하지만, 이 파일은 **원본 저장소에 포함되어 있지 않습니다**(다운로드 동작이 클라이언트 측 데모). 따라서 해당 표의 실수치는 원본에 존재하지 않습니다.

3. **이미지 전사 중 일부 추정/판독불가 표기.** 저해상도 다이어그램의 작은 라벨과 **총장님 친필 메모(필기체)** 일부는 `[추정: …]` 또는 `[판독 불가]`로 명시했습니다. 해당 `.md`의 메모 참조.

4. **인터랙티브 차트 페이지는 정적 이미지가 없음.** `grad_s1_3_regional` 등은 Chart.js/Plotly/D3로 런타임 렌더링 → 화면 이미지 대신 **그 기반이 되는 숫자 배열 전체**를 표로 추출(데이터 손실 없음).

5. **외부 CDN 라이브러리는 아카이브 대상에서 제외**(코드 자산이며 콘텐츠 아님): Chart.js 4.4.1, D3 7.8.5, Plotly 2.26.0, qrcodejs 1.0.0, Google Fonts(Nanum Gothic).

6. **사이트가 인용한 외부 링크**(아카이브 대상 외, 각 페이지 `## 미디어·링크 목록`에 기록):
   부산대 공식(`pusan.ac.kr`, `con/picee/pnurise/bi.pusan.ac.kr`), 네이버 뉴스, 교수신문 기사 등.

7. **작업 환경 부수효과.** PDF의 한글 텍스트 추출을 위해 일부 작업에서 **PyMuPDF(`pip install --user pymupdf`)가 사용자 Python에 설치**되었습니다(시스템 전역 아님). 불필요하면 `pip uninstall pymupdf`로 제거 가능합니다.
